# 事件分类学（catalyst-calendar）

日历条目的入类闸、类型枚举与判例。纲是「入类第一闸」：类型只是闸门之后的归位标签，早期"以类表为纲"的写法作废。
**类型封闭枚举的判定源=`scripts/check_calendar.py` 里 `EVENT_TYPES` 现值，本文件 §2 表是给人读的镜像**——两者不一致时以现值为准，包内一条命令可自查（命令与落位见 `README.md` §五 注行）。

---

## 1. 入类第一闸（每条目先过二选一，否则根本不入日历）

① **已有披露在场且含明确 `YYYY-MM-DD`**——公告/函件原文写得出的完整日期，锚=公告索引号/函件号/URL；
或 ② **statute 规则推导且适用条件在锚内可判**——当场取回的法条原文含可判定的适用条件（主体类别、报告期类型），
条件不满足即拒推。**快报期限无适用条件者不推**。
法定锚值规格：`statute:<法名>第N条(<要点短引>)`——名称+条号+短引三件齐，禁裸串；sources 对应行 `kind=statute` 且 ref 可复核。

**明令禁止**：
- **任何日期算术**：「公告日+360 天→截止日」这类推算全线不产行——起算日、自然日还是交易日、含不含首尾、变更如何覆盖，全都没有定义。公告原文明写完整截止日的，取原文日期、锚=该公告；公告未写的，**没有这一行**；
- 事后追记项冒充前瞻事件（见 §3「已发生动态」附注区）；
- 年粒度/月粒度指标强配一个日（会诱导补造某一天）。

## 1.5 入类第二闸·信息量闸（第一闸过后还要过这一闸）

**第一闸只证「日期是真的」，不证「这个日子值得盯」。** 日期真实但零信息量的条目同样不入日历——
把「补选独立董事」这类纯治理例行议案排进日历，是用合规动作冒充催化剂：它每天都真实发生，却不带任何可盯的内容，
读者按日历分配注意力会被稀释。故设第二闸。

判据是**议案性质的机械比对**（看公告原文写了什么议案），**不评估该事件对股价的影响**——
铁律 3 禁的是涨跌预判与褒贬，本闸禁的是零信息量，两者不冲突，本闸也不产出任何方向性表述。

- **A 正面清单（命中其一即保留行）**：增发／配股／可转债／回购注销等资本变动；重大资产重组、收购或出售资产、对外投资（含设立基金、合资）；关联交易；控制权变更、协议转让、要约收购及其豁免；利润分配与送转；股权激励／员工持股计划草案；对外担保额度、对外财务资助、大额综合授信；变更会计师事务所（换所）、非标意见背景下的续聘、罢免或非正常换届的董事改选；风险警示与退市相关议案。
- **B 免入清单（会议仅含这些议案时不产行）**：因个人／工作原因辞职后的独立董事、董事、监事补选（公告无异议表述、无反对票）；续聘原审计机构且无非标意见背景；章程／内控制度／议事规则的修订；变更公司全称、证券简称、注册地址、经营范围（非主业变更）；因转股或行权导致的被动变更注册资本；提请召开股东会的程序性议案；例行授权董事会办理小额事务；董监高薪酬津贴的例行调整。
- **C 混合情形（同时命中 A 与 B）**：**保留行，且「事件」列必须点名那个让它入表的 A 类议案**，写作「第 N 次临时股东会（〈A 类议案名〉）」。只写「第 N 次临时股东会」=读者看不出这一天为什么要盯，按不合格回改。
- **D 免入 ≠ 未检索到**：免入是「查到了、判为免入」，必须进 `progress.md` 弃条记录并写明命中 B 的哪一项；「未检索到」是取数面无命中。两者混写等于把主动过滤伪装成数据空档。

**第二闸不在机检面内**：机检只判形状（与「绿灯不证防线」同口径），这一闸靠人审与证据层兜底，
不新增机检道次、不改 `EVENT_TYPES`。

## 2. 类型枚举与主源锚型（闸门之后才归位；「类型×必配锚型」=机检 `EVENT_TYPES` 与 `TYPE_ANCHORS` 现值，下表为镜像）

| 类型 | 例（均有明确日期才可入） | 主源 | 必配锚型 |
|---|---|---|---|
| 回购 | 方案期限截止日（公告明写）/ 实施窗口开启日 | `buyback` 域直查 | 公告索引号或域 ref |
| 激励 | 授予登记日 / 归属日 / 行权窗口开启·截止日 | `esop` 域 | 同上 |
| 解禁减持 | 解禁日+规模（披露口径）/ 减持计划进展与到期 | `disclosure_cn`；原表缺口时 cue-research ≤1 | 披露原文锚；research 件 L3（§4.3） |
| 监管 | 问询函回复期限 / 警示整改期限 | `regulatory_cn` | 函件号 `〔〕` 规范式 |
| 分红 | 派息登记日 / 除权日 / 股东大会通过的分红议案实施日 | `disclosure_cn` | 公告索引号 |
| 法定 | 定期报告法定披露期限（条件可判的推导） | `statute` + 规则式推导 | **必 statute 规格串** `statute:<法名>第N条(<要点短引>)`（当场取回，禁裸串/不写死） |
| 股东大会 | **过 §1.5 第二闸**的议案类会议（年度/临时），股权登记日、现场会议日——仅含补选独董、续聘原审计机构等例行议案者免入，见 §1.5 B | `disclosure_cn` | 公告索引号 |
| 说明会 | 业绩说明会 / 投资者说明会（召开日） | `disclosure_cn` | 公告索引号 |
| 风险警示 | 退市风险警示、其他风险警示（ST/*ST）**实施或撤销生效日**（类型列取码内字面值「风险警示」，写全称即出枚举） | `disclosure_cn` | 公告索引号 |
| 停复牌 | 停牌 / 复牌**生效日** | `disclosure_cn` | 公告索引号 |

三项处置：**回购进度节点（1%、2%）**无事前日期、属事后追记→移出日历，见 §3 附注区；
**考核目标披露年**年粒度→降为激励行的属性列（「事件」列括注，不占独立行）；**快报法定期限**无条件者不推。

不在上表内的事件（宏观数据、行业会议、传闻、券商点评里的「预计」）一律不入。
**入表另须过 §1.5 第二闸**：类型对得上、日期也真的，但议案零信息量（§1.5 B）者免入。

## 3. 「已发生动态」附注区（不占日历行）

回购做到 1%/2%、减持实施中进度这类**无事前日期、发生即成过去**的披露动态：归入 calendar.md 末「已发生动态」附注区，
每条带公告锚+发生日，供读日历的人了解背景；**绝不回填成前瞻行**。此区不是第七类，是叙述区。

## 4. 判例（实跑形状可溯）

### 4.1 同一公告多事件拆行
一条公告承载多个可盯日期时**按事件拆行，每行独立带锚**（同一索引号重复是特性不是冗余——每行须自足）。
- 美的 2026-08-29《中期利润分配方案（董事会通过，待股东会）》（AN202608281828644258）→ 拆两行：
  「股东大会审议该议案」（日期=会议通知/会议日本身在场才入，锚=本方案公告+后续会议公告）与「登记日/除权日」
  （**未披露则不入**，届时新公告到场才建行）；
- 变更类公告（amendment）单独成行且**原方案行不删**：原方案状态「已变更→指向变更公告锚」，两行并存读得出方案演化。
- 回购方案公告含「期限 360 天」字样而无截止日 → **无行**（§1 算术禁令）；公告原文写明「截至 YYYY-MM-DD」→ 一行，锚=该公告。

### 4.2 窗口外余档：独立列，不挪锚
六列形制第 5 列专职余档：值=空，或 `窗口外余档(YYYY-MM-DD，早于/晚于窗口端)`；**来源锚列永远末列纯锚**——
早先"同行末列加注"的写法让注和锚挤在同一格（歧义源头），已废。机检对窗外条目查余档列空置，空置即 FAIL；
余档列有值而锚列为空的裸注同样 FAIL——注与锚各归各列，互不顶替。

### 4.3 research 件 L3 标注
解禁/减持原表经 cue-research 取得：锚=`conv_id+落盘路径`，状态列加「L3·待人工核」；
**入历前逐条过披露域在场核查（L1 前置，同姊妹件预期池的在场核查纪律）**——只在深研稿出现、披露面查无的日期不入表。
来源分歧双条并列不仲裁，各带各锚。

### 4.4 补类归位判例
- **停复牌**：「复牌生效日 YYYY-MM-DD」入「停复牌」类（锚=停牌/复牌公告索引号），不并入重大事项杂项；
- **风险警示生效**：ST/*ST 实施与撤销各有「生效日期」，入「风险警示」类（类型列字面值）；只有「被实施」公告而无明确生效日的，
  按 §1 闸一处理——公告日≠生效日，查无生效日即不入行，附注区记一句；
- **说明会**：「业绩说明会拟于 YYYY-MM-DD 召开」入「说明会」类（雨虹型通知公告 AN202604161821273798 形制）；
  纪要到手属素材层，不改日历行状态之外的任何事。
类型列的判定=`EVENT_TYPES` 现值；表内类型名与码内字符串逐字对应，**镜像若与现值不一致以现值为准**（自查命令同上）。

### 4.5 第二闸判例（实跑两例，可溯）

- **免入例（利通电子 603629，2026-10-13 第三次临时股东会）**：会议**仅**审议《关于补选第四届董事会独立董事的议案》——
  原独立董事路小军因个人工作原因辞职，董事会提名白建川补选，公告对候选人资格无保留、无反对票表述。
  第一闸过（会议日 2026-10-13 在场且含明确日期），**第二闸不过**：命中 §1.5 B 首项 → **不产日历行**，
  在 `progress.md` 弃条记录写明「第二闸免入：仅含因个人原因辞职后的独董补选」。
- **保留并改写事件列例（沪电股份 002463，2026-10-15 第二次临时股东会）**：议案含续聘立信（命中 B）+ 分红回报规划
  + 新增综合授信折合 140 亿元（总额 360 亿→500 亿）、新增对外担保 35 亿元（总额 58 亿→93 亿）。
  命中 §1.5 A（大额综合授信、对外担保额度）→ **保留行**，且事件列按 §1.5 C 点名实质议案，
  写作「第二次临时股东会（新增综合授信及对外担保额度）」——**不得只写「第二次临时股东会」**，也不得只写「续聘审计机构」。

## 5. 类型速判坑

- 「定期报告披露」条目优先取公司自己的《预约披露时间公告》（在场时锚它），法定截止日为**下限兜底**——两者都在排两行；
- 员工持股计划「届满/终止」是事件行（带各自主源公告锚），归属日与终止日不同源分开带；
- 减持「预披露→实施中→完成」三行各带各公告索引号，合并会吞掉状态变化；
- 分红类与股东大会类交叉时（分红议案交股东会）：**议案在股东大会类，实施日（登记/除权）在分红类**，两行两锚不互替。
- 股东会行只写「第 N 次临时股东会」而不点名实质议案 → 按 §1.5 C 回改；**只**审议补选独董／续聘原审计机构／章程修订的会 → §1.5 B 免入，不产行（免入记弃条，不写「未检索到」）。
